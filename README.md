## Настройка и запуск

Предполагается, что на хостовой системе присутствует и настроен *docker*, *docker-compose*

### Системные требования

Данный пример разработан и проверен на ОС *Ubuntu 24.04.2*, предпологается, что без каких-либо изменений этот код может работать на любых других *Linux* системах. В *Windows* возможно придется установить необходимое ПО.

### Используемое ПО

Стандартный способ запуска в терминале с использованием необходимых команд (в директории с *docker-compose.yml*)

Другое используемое ПО (в Ubuntu будет установлено автоматически, см. следующий раздел):

- python (желательно версия не ниже 3.8)
- pipenv (для виртуальных окружений python)

Для работы с кодом примера рекомендуется использовать VS Code.

В случае использования VS Code следует установить расширения
- Docker
- Python

### Запуск проекта

Для запуска примера:

```
docker-compose up --build
```

Просмотр логов: 

```
docker-compose logs [название контейнера]
```

Тестирование 

(тесты долго отрабатывают, ждать нужно примерно 2 минуты)
``` 
# Вывод логов тестов
docker logs -f tests-runner
```

завершение работы:

```
docker-compose down
```
